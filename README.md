# ML Student Performance Prediction and Model Evaluation

## Description

This project applies Machine Learning techniques to predict student exam performance and evaluate regression and classification models using the Student Performance dataset.

The analysis follows a complete machine learning workflow, including Exploratory Data Analysis (EDA), data preprocessing, model training, prediction, evaluation, and performance comparison.

## Objectives

- Perform Exploratory Data Analysis (EDA)
- Identify numerical and categorical variables
- Analyze missing values and potential outliers
- Examine relationships between features and `exam_score`
- Build a Linear Regression model to predict exam scores
- Evaluate regression model performance
- Create a Pass/Fail classification target using 50 marks as the passing threshold
- Train and evaluate a classification model
- Compare training and testing performance
- Identify possible overfitting or underfitting
- Generate meaningful insights about student performance

## Features Used

The analysis includes relevant student-related features such as:

- Study Hours Per Day
- Attendance Percentage
- Sleep Hours
- Social Media Hours
- Netflix Hours
- Exercise Frequency
- Mental Health Rating
- Other suitable variables from the dataset
